## Knowledge base themes

### 1. Project lifecycle

- Initiation validates the idea and aligns stakeholders
- Planning turns the idea into a backlog and milestone plan
- Execution keeps the team moving with visibility, quality, and blockers
- Release manages deployment, verification, and stakeholder communication
- Retrospective turns lessons into action

### 2. Team operating model

- Product, engineering, and project roles remain aligned around outcomes
- Communication is regular, visible, and clear
- Risks are named early and addressed with ownership

### 3. Shared artifacts

- One-pager / project charter
- Risk register
- Backlog and acceptance criteria
- Release notes and deployment checklist
- Retrospective action items

## How to use this knowledge base

- Use the overview to understand the framework
- Use the role documents to clarify responsibilities
- Use the lifecycle docs for practical guidance by phase
- Review the process docs regularly as team practices evolve

## Team playbook

The OctoAcme PM system is intentionally lightweight: it should help the team align, reduce ambiguity, and ship reliable outcomes without adding unnecessary ceremony.
