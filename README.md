# OctoAcme Project Management Knowledge Base

This repository captures the team’s project management tribal knowledge and makes it easy to access, reuse, and improve over time.

## Why this exists

The materials in this repository distill recurring patterns, responsibilities, rituals, and decision points used by the OctoAcme team to initiate, plan, execute, release, and improve projects.

## Knowledge base structure

- Overview and navigation
- Project initiation guidance
- Project planning guidance
- Execution and tracking guidance
- Risk and communication guidance
- Release and deployment guidance
- Retrospective and continuous improvement guidance
- Personas and role definitions
- Request/update process for new content

## Team use

- Use this repository as the team’s living source of truth for PM practices.
- Keep it updated as the team learns and evolves.
- Add process language and examples to the project docs and review them with stakeholders.

## How to propose an update

Use the issue template in `.github/ISSUE_TEMPLATE/add-update-content-to-process-docs.yml` to request new content or changes to existing process documents.

## Recommended operating rhythm

- Update process docs when a team practice changes.
- Review the knowledge base during planning and retrospectives.
- Treat the docs as a lightweight system for coordination, not a heavy approval process.

## Core principles

- Customer-first thinking
- Clear ownership and accountability
- Iterative delivery and measurable outcomes
- Transparent communication and risk escalation
- Learning from retrospectives and feedback
